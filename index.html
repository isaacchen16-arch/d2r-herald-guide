《暗黑破壞神 II：獄火重生》3.3 恐懼使者全地圖刷法總策略

五個章節的世界之石碎片全開｜以恐懼使者數量／時間最大化為目標

一、核心規則

T1～T4：升階期
每個 zone_data_id 的任務只有一件事：生出一隻恐懼使者。
一出生就換區。
T5：收割期
不再遵守「一隻就走」。改成榨取該區域的剩餘怪量與恐懼使者產能。
區域完成度 X 是局部值
只有相同 zone_data_id 的地圖共享 X；不同區域彼此不累積。
恐懼使者階級是全局值
同一場遊戲中，T1 → T2 → T3 → T4 → T5 持續往上，不因切換章節而重置。
一句話：低階省圖，高階榨圖。T1～T4 用低機會成本區域支付升階成本；進 T5 後，再把世界之石要塞、秘密乳牛關、塔拉夏的古墓、剝皮叢林等高價值區域完整榨乾。

二、T1～T4 升階期：統一演算法

選低／中價值區域→ 一路殺，不先繞圖→ 沒出恐懼使者就繼續→ 恐懼使者出現→ 立刻換新的 zone_data_id

如果一個區域完整清光仍沒出恐懼使者，代表該區域可供觸發的怪物已經耗盡；直接換下一個區域，不需要另外切換成所謂「乾旱模式」。真正要做的是按機會成本由低到高消耗區域。

建議升階起始路線

蜘蛛洞窟 → 蜘蛛巢穴 → 外圍荒原 → 絕望平原 → 罪罰之城 → 火焰之河 → 邪惡洞窟 → 古老石墓
只跑到 T5 為止；每出一隻就立刻跳下一個區域。剩餘未用區域全部保留給 T5。

三、T5 收割期：策略反轉

一進 T5，開始優先刷「每小時恐懼使者數」最高的剩餘區域。恐懼使者出現後，X 會歸零，但如果該區域還剩大量集中怪物，就重新累積 X，繼續追下一隻 T5。

繼續刷
恐懼使者出得早、地圖仍剩約 50% 以上集中怪、後續路線順。
換區
只剩 20～30% 零散怪、需要回頭找，而下一個完整高價值區域更快。

T5 第一梯隊

世界之石要塞／毀滅王座 → 秘密乳牛關 → 血腥丘陵 → 剝皮叢林 → 秘法聖殿 → 尼拉塞克的神殿／怨慟之廳 → 苦痛之廳 → 憎恨囚牢 → 七座塔拉夏的古墓 → 冰凍苔原 → 大教堂／地下墓穴 → 死亡之殿
S：T5 高價值／深清A：高優先B：正常C：低優先／升階可犧牲路過：不拿來累積 X

補充：幾個最常犯的錯
  • 把「換地圖」誤以為等於「換 X」：真正要看 zone_data_id。
  • 低階恐懼使者一出仍繼續刷同一區域：X 已歸零，下一階通常不划算。
  • T5 恐懼使者一出就走：高價值大區域可能還能再生第二、第三隻。
